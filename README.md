# 🛒 EcomJoin WooCommerce Integration Plugin

Official WooCommerce plugin for **EcomJoin** — The AI-powered COD E-commerce Automation Platform.

## 🌟 Features
* ⚡ **Real-time Order Sync:** Automatically passes new WooCommerce orders to EcomJoin via Webhooks.
* 🤖 **AI WhatsApp Qualification:** Enables automated WhatsApp confirmation and customer care.
* 🚀 **Lightweight & Fast:** Non-blocking asynchronous requests to ensure zero delay in store checkout.

## 📦 Installation
1. Download or clone this repository.
2. Zip the folder as `ecomjoin-woocommerce-plugin.zip`.
3. Upload to your WordPress Admin panel (`Plugins -> Add New -> Upload Plugin`).
4. Activate the plugin.
5. Go to `WooCommerce -> EcomJoin AI` and enter your EcomJoin Webhook URL and API Key.
